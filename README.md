# 🏆 Erteleme Sanatı Ustası

> *"Bugün yapacağım işleri yarına bırakmak, yarının sorunlarını bugünden çözmektir."*  
> — Bilinmeyen bir erteleme filozofu (muhtemelen ben)

## 🚀 Bu Ne Lan?

Bu repository, insanlık tarihinin en büyük keşiflerinden biridir: **Erteleme Sanatının Matematiksel ve Felsefi Kanıtı**.

`erteleme_ustasi.py` adlı bu kutsal script, herhangi bir görevi alır ve onu **kuantum seviyede, geri dönüşsüz biçimde** erteler. Üstelik bunu yaparken size o kadar mükemmel bir bahane verir ki, vicdanınız bile "tamam abi, haklısın" der.

## ✨ Özellikler

- Gerçekten çalışır (deneyin, göreceksiniz)
- 10 farklı absürt ama ikna edici bahane
- Dramatik yükleme animasyonu (3 nokta, bilimsel)
- Komut satırından görev alabilir
- Hiçbir işe yaramaz, ama tam da bu yüzden mükemmeldir
- Kedi dostu (kediler onaylar)

## 💻 Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/erteleme-sanati-ustasi.git
cd erteleme-sanati-ustasi
python3 erteleme_ustasi.py "ödevimi bitirmek"
```

Veya sadece:

```bash
python3 erteleme_ustasi.py
```

Çıktı örneği:

```
🎭 Erteleme Sanatı Ustası Devrede! 🎭
Görev: ödevimi bitirmek
Analiz ediliyor...
✨ MÜKEMMEL BAHANE: Kuantum belirsizliği prensibine göre bu görevin yapılıp yapılmayacağı henüz gözlemlenmedi.
👍 Görev başarıyla ertelendi. Tebrikler, bir adım daha özgürsün.
```
